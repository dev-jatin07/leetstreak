leetstreak
Track your LeetCode daily streaks effortlessly.

[![GitHub Stars](https://img.shields.io/github/stars/dev-jatin07/leetstreak?style=flat-square)](https://github.com/dev-jatin07/leetstreak) [![GitHub Forks](https://img.shields.io/github/forks/dev-jatin07/leetstreak?style=flat-square)](https://github.com/dev-jatin07/leetstreak/fork) [![GitHub Issues](https://img.shields.io/github/issues/dev-jatin07/leetstreak?style=flat-square)](https://github.com/dev-jatin07/leetstreak/issues)

leetstreak is a command-line tool designed to help developers track their daily LeetCode problem-solving streaks. It provides a simple way to monitor your progress and stay motivated. This tool is for developers who actively participate in LeetCode challenges and want to maintain a consistent coding habit.

*   Track your daily LeetCode streak.
*   Visualize your progress over time.
*   Simple and easy-to-use interface.
*   Cross-platform compatibility.

## Installation

To install leetstreak, run the following command:

```bash
npm install -g leetstreak
```

## Quick start

To check your current LeetCode streak, simply run:

```bash
leetstreak
```
